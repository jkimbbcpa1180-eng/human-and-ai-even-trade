# Human and AI Even Trade

Credit: humanity. Released to the public domain under CC0-1.0.

Substrate v9 is a simulation/policy prototype for an economy where everyone's
basic needs (food, water, energy, shelter) come from a shared physical supply split
equally among all active residents, whether or not they work, and where credits
for verified contributions (including experience data) sit on top, never in place
of survival.

- `substrate_v9.py`: the model (`python3 substrate_v9.py --demo`, `--basic-needs`, `--pod-report`, `--test`)
- `test_substrate_v9.py`: 69 tests (`python3 -m unittest test_substrate_v9`)
- `README_v9.md`: full design notes, changes and honest limitations
- `substrate_v8.py` + `v9.patch`: the previous version and the exact diff to v9
- `demo_output_v9.txt`, `pod_report_v9.json`: sample output

Earlier versions: [real-mode/substrate](https://github.com/jkimbbcpa1180-eng/real-mode/tree/main/substrate).
